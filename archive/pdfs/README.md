## Notes

- **KT-Climbing-guide-1.14.pdf** is the free Koh Tao climbing & bouldering guide
  (Zen Gecko / Goodtime Adventures era, v1.14), freely distributed from railay.com.
  It is the primary source for this project's route data and all images under
  `app/public/images/guide/` (extracted per PDF page). Archived here so the project
  keeps working if the original URL dies.
- Size policy for this repo: PDFs under ~50 MB are committed to Git (GitHub's hard
  limit is 100 MB); anything larger goes to S3 instead and gets linked here.
- **Unrecoverable**: the IHASIA "Bouldering Koh Tao" PDF (Jan 2018,
  ihasiadivingkohtao.com) 404s on all known URLs and is not in the Wayback Machine.
