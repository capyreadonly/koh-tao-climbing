Koh Tao · Gulf of Thailand

Privacy — data not collected

For the Koh Tao Climbing iOS app (bundle com.kohtaoclimbing.guide), a community climbing guide for one island.

Apple App Privacy: Data Not Collected. The app works offline from files inside the bundle. It does not create accounts, show ads, or run analytics.

Effective 28 August 2026. This page is only about the Koh Tao Climbing iOS app and the matching static web guide. It is not a policy for any other product.

What the app is

Koh Tao Climbing is an original community-built guide to rock climbing on Koh Tao, Thailand — crags, routes, topos, photos, trip reports, and an offline map of Koh Tao and Nang Yuan. It is not a white-label guidebook template.

What we collect

Nothing. The iOS app does not collect, transmit, or sell personal data. There is no sign-in, no profile, no cloud sync, no advertising identifier use, no crash reporter, and no analytics SDK.

  • Guide JSON, photos and map tiles ship inside the app. Browsing them does not use the network.
  • The app does not request location permission. The map is a bundled OpenStreetMap tile set for this island, not a live GPS tracker.
  • There are no accounts to delete because there are no accounts.

When a link leaves the app

Some screens offer optional links to public sources (for example Mountain Project, 27crags, theCrag, operator websites) or to this GitHub Pages site. Tapping one opens Safari. Those destinations have their own policies. The app does not send them a user account or analytics payload because it has none.

GitHub’s servers may log ordinary web requests if you open this page or the web guide in a browser. That is GitHub Pages infrastructure, not data collection by the iOS app.

Children

The app does not collect data from anyone, including children. It is a reference guide, not a social network.

Changes

If the app’s privacy behavior changes, this page will be updated and the date above will change. The current behavior is: data not collected, offline-only guide.

Contact

Questions about this policy: open an issue on the project repository — github.com/capyreadonly/koh-tao-climbing/issues. Support details are on the support page.
